Handwritten C++ Data Structures (TCS 302 Alignment)

The terminal C++ executable (`prioritiser.exe`) relies on zero STL containers for core algorithms. Below is how each custom data structure operates:

1. Binary Max-Heap (MaxHeap)
Dynamically ranks topics by calculated past-paper priority score.
void siftUp(int i); void siftDown(int i); // O(log N)
2. Directed Graph (PrereqGraph)
Adjacency list with DFS cycle detection and Topological Sort.
vector<string> topologicalSort(); // Kahn's Algorithm
3. Binary Search Tree (TopicBST)
Provides rapid O(log N) search by Topic ID and in-order traversal.
Topic* search(string key); void inOrder();
4. Stack ADT (MyStack)
Linked-list stack powering multi-level syllabus undo / redo.
void push(T val); T pop(); bool empty();
5. Queue ADT (MyQueue)
Linked-list queue organizing weak topics into revision pipeline.
void push(T val); T pop(); int size();
6. Singly Linked List (PlanList)
Dynamically links allocated study sessions for clean reporting.
struct PlanNode { int order; string id; PlanNode* next; }
